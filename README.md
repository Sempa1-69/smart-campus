# Smart Campus AI

Учебная веб-платформа управления инфраструктурой кампуса: панель мониторинга аудиторий, IoT-устройств, энергопотребления и заявок с модулем обнаружения аномалий.

**Стек:** HTML5, CSS3, JavaScript (без фреймворков), Chart.js (CDN), localStorage, Git + GitHub Pages.

## Запуск

Откройте проект через локальный сервер (не двойным кликом):

- VS Code → расширение **Live Server** → *Open with Live Server* на `index.html`, или
- в папке проекта: `python -m http.server 8000` и откройте http://localhost:8000

Вход — любой email формата `name@domain.tld`, пароль от 4 символов, любая роль. Это **учебная имитация**, не настоящая защита.

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Login, выбор роли (Administrator / Engineer / Operator) |
| `dashboard.html` | 5 KPI, 3 графика (энергия по корпусам, тренд температуры, статус устройств), уведомления |
| `rooms.html` | 14 помещений, поиск, фильтры по корпусу и статусу (Normal / Warning / Critical) |
| `devices.html` | 26 IoT-устройств, поиск, фильтры, переключение online/offline |
| `incidents.html` | CRUD заявок: создание, изменение, удаление с подтверждением, поиск, фильтры |
| `analytics.html` | Аномалии, причины, уровень риска, рекомендации, симуляция датчиков |
| `settings.html` | Тема, название кампуса, профиль, сброс тестовых данных |

Общие элементы: sidebar, topbar с глобальным поиском (Enter → Rooms), колокольчик уведомлений, переключатель тёмной/светлой темы (сохраняется).

## Как работает «AI»

Это **не генеративный AI**, а статистика и правила, которые считаются в браузере и не требуют API-ключей.

1. **Пороги.** Температура: норма 18–27 °C, warning выше 27, critical ≥ 32. CO₂: норма < 1000 ppm, warning ≥ 1000, critical ≥ 1500. Энергия: warning при +30 % и critical при +60 % к базовой линии помещения (`baseline`).
2. **Z-score.** Текущее значение сравнивается со средним и стандартным отклонением последних 12 показаний. Если `|z| > 2` — значение помечается как статистическая аномалия. Для защиты от ложных тревог на «плоской» истории стандартное отклонение имеет нижнюю границу (`MIN_SD`).
3. **Рекомендации.** Правила «если–то» (`getRecommendation`): критический CO₂ → вентиляция, перегрев → кондиционер, пустое помещение с высоким потреблением → отключить технику. Серверная исключена из правила про пустые помещения.

Кнопка **«Симулировать показания»** на странице Analytics делает один шаг симуляции датчиков (значения тянутся к типичным, иногда случается выброс); режим «Авто» повторяет шаг каждые 3 секунды.

> Если нужен настоящий внешний AI API, его вызывают через собственный backend или serverless-функцию. Секретный ключ нельзя хранить в браузерном JavaScript.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Create Smart Campus AI dashboard"
git branch -M main
git remote add origin URL_РЕПОЗИТОРИЯ
git push -u origin main
```

Затем **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Для задания нужно минимум 5 осмысленных коммитов — делайте их по этапам (структура, данные, страницы, графики, AI).
